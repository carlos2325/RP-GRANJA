# Estructura (Silos / Instalación)

Documento de referencia para describir la estructura física: silos, depósitos, válvulas, bombas, sensores y cómo se relacionan con el sistema.

## Mapa lógico (ejemplo)

- Zona Agua
  - Depósito principal
  - Bomba de agua
  - Válvulas/relés
- Zona Ambiente
  - Temperatura/Humedad (DHT)
  - Ventilación/extractor
- Zona Iluminación
  - Luces IR / lámparas

## Qué falta para el diagrama final

- Foto o esquema del circuito (o un PNG/PDF)
- Cómo se nombran las zonas en la granja (norte/sur, cerditos, etc.)
- Qué pines corresponden a cada elemento (esto lo saca `config.py`)

Cuando tengas un diagrama (imagen o PDF), lo añadimos en `docs/hardware/` y lo enlazamos desde la vista **Hardware** y **Docs**.
